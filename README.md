# Traductor Español - Portugués (Python)

Aplicación de escritorio desarrollada en **Python** para traducir entre español y portugués, con interfaz gráfica, gestión de base de datos local y reproducción de audio.

## Características principales
- **Interfaz gráfica de escritorio** para ingresar texto y visualizar traducciones de forma clara.
- **Base de datos local** para almacenar y consultar información del diccionario/historial.
- **Servicio de audio** para escuchar pronunciación o apoyo auditivo.
- **Alertas y apoyo lingüístico** (por ejemplo, falsos cognados/falsos amigos).

## Estructura del proyecto
- `aplicación.py`: Punto de entrada y lógica de la interfaz gráfica.
- `src/`: Módulos principales del motor de traducción y servicio de audio.
- `base de datos/`: Gestión y archivo de base de datos local.
- `.gitignore`: Exclusión de archivos temporales y caché de Python.
